# Python-Readme
Gradebook Management System
Section A: I wrote a program that asks for the number of students, then uses a loop to collect each student's name and grade for one subject. A while loop validated each grade, and the program  asked until the user entered a whole number from 0 to 100. The program totaled the grades, worked out the class average, and displayed each student's grade next to that average.

Section B: lists and tuples. I increased the program to handle three subjects . Each student is stored as a tuple of their name and a list of grades. The program calculates each student's average across all subjects and finds the highest and lowest grade in each subject. It then prints a summary table showing each student's name, subject grades and average.

Section C: dictionaries. I replaced the list of tuples with a dictionary. Each student's name is a key, and its value is another dictionary of subjects, each holding a list of grades. I added a menu-driven program that can add a student, add grades, remove a student, view all grades for one subject, and search for a student to show their grades and average.
